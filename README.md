
# Filmlistan

Filmlistan är en Android-app skapad med Kotlin och Jetpack Compose.

## Funktioner
- Lägga till filmer
- Visa filmer i en lista
- Markera filmer som sedda
- Ta bort filmer

## Teknik
- Kotlin
- Jetpack Compose
- Android Studio

## Syfte
Projektet är skapat för att träna på Android-utveckling, Git och GitHub.

## Git och GitHub

I det här projektet har jag tränat på att använda Git och GitHub.

Jag har lärt mig att:
- Kontrollera ändringar med git status
- Förbereda filer med git add
- Spara ändringar med git commit
- Ladda upp projektet med git push
